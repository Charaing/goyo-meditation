# GOYO 고요

조용한 명상과 호흡을 위한 단일 파일 웹앱입니다. `index.html` 하나로 서버, 데이터베이스, API 키, 회원가입 없이 동작합니다.

## 주요 기능

- **오늘 · 명상 · 호흡 · 기록 · 설정** 다섯 개 탭
- Canvas로 그린 레이어형 풍경 5종 (Misty Mountains, Moonlit Lake, Silent Forest, Ocean Horizon, Deep Space), 다크·라이트 모드
- 10개 주제, 28개 명상 프로그램 (검색, 시간·난이도·즐겨찾기 필터)
- 실제 경과 시간 기준 타이머 (일시정지 시간 제외, 백그라운드·새로고침 후 복구)
- 호흡 설정과 정확히 동기화된 호흡 구체, 균형·편안한·박스·자유 호흡
- Web Audio로 실시간 생성하는 자연의 소리 (비, 바람, 파도, 백색소음, 브라운 노이즈, 앰비언트)와 사운드 믹서
- 수면 모드, Zen 모드, 명상 일지, 캘린더, 주간 그래프
- 브라우저 음성 안내(Web Speech API), 내 안내 음원 업로드
- JSON 내보내기/가져오기 (형식 검증, 중복 방지)

## 참고

- 모든 기록은 기기 브라우저(localStorage)에만 저장되며 어디에도 전송되지 않습니다.
- 자연의 소리는 녹음 파일이 아니라 생성된 소리입니다.
- 브라우저 정책상 소리는 첫 터치 이후에 켜지며, 화면 잠금이나 백그라운드에서는 기기에 따라 소리가 멈출 수 있습니다.
- 명상·호흡·수면 기능은 휴식을 돕는 도구이며 의학적 치료가 아닙니다.
